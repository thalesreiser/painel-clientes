# painel-clientes

Painel por cliente montado a partir de um arquivo JSON de configuração e dos dados que o cliente já
exporta do sistema dele (CSV ou XLSX). Dois templates: `financeiro` (escritórios contábeis com BPO
financeiro) e `entregas` (transportadoras e distribuidoras).

Este repositório público contém apenas o código e as demos com dados fictícios. As configurações e os
dados reais de clientes ficam fora dele ([ADR 003](docs/adr/003-public-code-private-config.md)).
